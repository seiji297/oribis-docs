# prompt/ — プロンプトテンプレート

## 構成

- `character/` — キャラクター定義（人格・外見・声・口調・好み）
- `system/` — システム共通ルール（出力形式・好感度メカニクス・マーカー仕様）

## L1 / L2 生成方法

| 層 | 用途 | 生成方法 |
|----|------|---------|
| L1 | フルプロンプト（通常対話） | `character/{name}.md` + `system/output-rules.md` を結合 |
| L2 | 圧縮プロンプト（コンテキスト制限時） | L1 を要約・圧縮して生成 |

L2 は L1 の派生物。character/ と system/ のソースを更新した後、L2 も再生成すること。
