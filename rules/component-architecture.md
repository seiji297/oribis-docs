# Oribis コンポーネントアーキテクチャ

> 作成: 2026-05-04

---

## 設計原則 — コンポーネント指向

- **1コンポーネント = 1オーナー**: ディレクトリ単位でオーナーを明確化
- **境界は型で定義**: コンポーネント間の依存は `types/` の型定義を経由
- **副作用の局所化**: 各コンポーネントの状態変更は自身のディレクトリ内で完結

---

## コンポーネントオーナーシップ

**1ディレクトリ = 1エージェント**。他エージェントのコンポーネントへの変更は事前合意必須。

| 共有ファイル | オーナー | 調整方法 |
|------------|---------|---------|
| `src/types/` | sysdev-4 | 型追加は提案→承認 |
| `src-tauri/src/lib.rs` | sysdev-3 | 他エージェントのコマンド追加はPR経由 |
| `Cargo.toml` / `package.json` | 変更時は全エージェントへ周知 |
| `src/App.tsx` | sysdev-4 | 他エージェントは最小限の追加のみ |
