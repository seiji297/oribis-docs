# テスト要件 設計書

**バージョン**: 1.0（anima-spec.md §24 より分割）
**最終更新**: 2026-04-28

---

## 1. 単体テスト

- 好感度tier判定（境界値）
- マーカーパース（全種類、正常・異常系）
- 永続化（save/load/破損）
- 履歴整形・圧縮
- 発火制御（クールダウン・確率）
- キャッシュ抽出
- モード判定
- 記憶検索・保存
- イベントカウンタ更新・集計
- タスク状態管理

---

## 2. 統合テスト

- AI Mode: ユーザー発話 → 応答 → 履歴追加
- AI Mode: Animaイベント → 応答 → 履歴追加
- Cache Mode: キャッシュ抽出のみ
- Hybrid Mode: AI失敗 → Cacheフォールバック
- 好感度更新 → 次回応答に反映
- 記憶保存 → 次回検索でヒット
- カウンタ更新 → L3注入確認
- タスク追加・更新 → UI反映

---

## 3. キャラ品質テスト

- L1単独 vs L1+L2 の長会話比較
- 好感度tier別のトーン変化確認
- 業務応答品質の好感度非依存性
- メイン応答とAnima応答のキャラ一貫性
- カウンタ参照時の自然な指摘表現

---

## 4. CLI互換性テスト

- Claude CLI / Codex CLI で同一動作
- マーカー解釈の一貫性
- フォールバック動作

---

## 5. パフォーマンステスト

- 24時間運用後の履歴・記憶サイズ
- LLM呼出頻度
- コスト測定
