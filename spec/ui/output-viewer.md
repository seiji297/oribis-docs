# Output Viewer

## Overview

# FEAT-③: 出力ファイルビューワー (Output Viewer) — 案C採用

作成: 2026-04-24 / Producer指示・案C確定

## 概要

チャット/ターミナル出力に含まれるファイルパス（.png/.jpg/.svg/.html等）を自動検出し、
サイドパネルまたはチャットインラインに表示する汎用出力ビューワー。
画像専用ではなくファイル種別問わず対応（案C）。

## 却下した案

- 案A: Tauri fsウォッチ → 特定ディレクトリ監視（外部ツール依存）
- 案B: Claude API直接呼び出しに切替（CLIバイパス必要、アーキテクチャ変更大）

## 技術設計方針

### 検出ロジック
- CLIストリーム出力をリアルタイムパース
- 検出パターン: `/[^\s]+\.(png|jpg|jpeg|gif|webp|svg|html|pdf)/g`
- Tauriバックエンドでファイル存在確認（`fs::metadata`）

### 表示方式
- チャットメッセージ内にインライン表示（画像: `<img>`、HTML: iframe、SVG: 直接埋込）
- 「出力パネル」サイドドロワー（折りたたみ可）

### 対応ファイル種別
| 種別 | 表示方法 |
|------|---------|
| .png/.jpg/.gif/.webp | `<img>` インライン |
| .svg | SVG直接埋込 |
| .html | iframeサンドボックス |
| .pdf | リンク（ブラウザで開く） |
| その他 | ファイル名リンクのみ |

## 受け入れ条件 (AC)

- AC-1: CLI出力のファイルパスが自動検出される
- AC-2: 画像ファイルがチャットにインライン表示される
- AC-3: SVGが正しく描画される
- AC-4: HTMLがサンドボックスiframeで表示される
- AC-5: 非対応ファイルはリンクとして表示される
- AC-6: 表示パネルを閉じる/開くことができる
