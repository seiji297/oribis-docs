# Pre-release Test Matrix

この表は「人間がリリース可否を判断できる機能保証表」。既存の全Vitest/WDIO/Cargo/Pythonケースをここへ全展開しない。各行は保証したい振る舞い単位で、配下の実行コマンドと対象ファイルは `test-inventory.md` と `manifest.json` に紐づける。

## 判定ルール

- `Level`: 何を保証するか。`Static` / `UT` / `IT` / `SIT` / `ST` / `AT` / `Release Gate`。
- `Runner`: 実行手段。`TypeScript` / `Vitest` / `Cargo` / `WDIO` / `WindowsQA Server` / `manual review`。
- `Environment`: 実行環境。`local-linux` / `wslg` / `local-windows` / `windows-qa-server`。
- `Gate`: 出荷判定への効力。`required` / `supporting` / `diagnostic`。
- `Diagnostic` は原因調査用。AT/ST/Release Gateの代替にしない。
- Windows実画面の受け入れは `windows-qa-server + real-gpu + actual-user-operation` の証跡だけを正とする。
